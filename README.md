# Kubernetes Training

Repo d'entraînement pour maîtriser Kubernetes, ArgoCD et Terraform,
en préparation du projet Capgemini (plateforme Azure mobilité/géolocalisation/péage).

## Structure
- `01-kubernetes-basics/` — Pods, Deployments, Services, Namespaces
- `02-argocd/` — Manifests GitOps
- `03-terraform/` — Infrastructure as Code
- `04-stockage/` — MongoDB et Redis
- `05-monitoring/` — Prometheus et Grafana
- `notes/` — Commandes utiles et glossaire

## Environnement de test
Killercoda (killercoda.com) scenario "Kubernetes Playground"
